# 双碳管理系统

1. ## 检查开发环境
   ```bash
   node -v //node版本大于16
   ```
2. ## 下载pnpm
   ```bash
   npm i pnpm -g
   ```
3. ## 配置淘宝源
   ```bash
   pnpm config set registry https://registry.npmmirror.com/
   ```
4. ## 安装依赖
   ```bash
   pnpm i
   ```

5. ## 运行项目
   ```bash
   pnpm run dev
   ```

6. ## 项目打包
   ```bash
   pnpm run build:prod
   ```
